# Library Collections and Filters Implementation Plan (M11, part A)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the route library be grouped into named collections (a route can be in several) and narrowed with filters (stars, length, climb, not ridden yet, loops only), with zips, multi-file imports and watched-folder subfolders filling collections, and backups and shared zips keeping them.

**Architecture:** Two new Room tables (schema v3, auto-migration) behind a `CollectionRepository`. The library's list stays one pure function, `arrange()`, which now takes a `LibraryFilters` value and the set of route ids the chosen collection allows. The import queue and the watched-folder scanner group routes through a small `ImportCollections` interface, so their JVM tests use a fake. Backups and shared zips carry collection names in optional JSON fields that older versions ignore.

**Tech Stack:** Kotlin, AGP 9.4.1, Jetpack Compose + Material3, Navigation3, Room 2.8.5 (KSP, exported schemas), DataStore Preferences, kotlinx.serialization, JUnit 6 (Jupiter) for JVM tests, JUnit4 + `MigrationTestHelper` for device tests.

**Spec:** `spec-singletrail.md` — §1 non-goals, §3 journey 2, §8.1 (library, Manage collections, route detail), §8.2 (tables `collections`, `route_collections`, schema v3), §8.4 step 7, §8.5 (sharing, backup, merge rules), §8.6, decisions D48 and D49, Appendix B "M11 — Library organizing". Read those sections before starting; this plan argues from them.

## Global Constraints

- Collection names are unique **ignoring case**; names are trimmed and inner whitespace collapsed; blank names are no names (spec §8.1, §8.2).
- A route can be in several collections; deleting a route or a collection removes only its memberships; deleting a collection keeps its routes (spec §8.2, §8.6).
- Length bands: up to 20 km (≤ 20 000 m), 20–40 km (≤ 40 000 m), over 40 km. Climb bands: up to 500 m, 500–1000 m, over 1000 m, same boundaries. Routes without elevation are hidden while a climb filter is on. *Not ridden yet* = no "last ridden" date (spec §8.1, D49).
- Sort, collection and filters are remembered across restarts; search is not; a remembered collection that was deleted falls back to *All routes* (spec §8.1).
- Zip → collection named after the zip without `.zip` (or the manifest's `collection`), including routes already in the library; several GPX at once → ask after the last one when two or more routes count; watched-folder subfolder → collection named after its own folder; single file → none (spec §8.4 step 7).
- New backup/zip fields are optional: older backups restore without collections, older app versions ignore them (spec §8.5). `BackupJson` already has `ignoreUnknownKeys = true`.

## Review Focus

1. **Names differing only in case or spacing** ("Waldegg loops" vs "  waldegg   LOOPS ") must land in one collection, not two. → Task 2, `namesAreUniqueIgnoringCaseAndSpaces`.
2. **A remembered or chosen collection that gets deleted** must show *All routes*, not an empty list forever. → Task 3, `a deleted collection falls back to all routes`.
3. **Zip names Android decorates** ("routes (1).zip", "Routes.ZIP") must lose only the extension. → Task 2, `zip names lose their extension, in any case`.
4. **A multi-file import whose files are the same route, or all already in the library as one route,** must count distinct routes and not ask for fewer than two. → Task 7, `two files of the same route don't ask about a collection`.
5. **A backup made before collections existed** (no `collections.json`, no `collections` per route) must restore exactly as before. → Task 9, `a backup without collections restores without them`.

/** A collection and how many routes are in it (spec §8.1). */
data class CollectionCount(val id: String, val name: String, val routes: Int)

@Dao
abstract class CollectionDao {
    @Query(
        """SELECT c.id AS id, c.name AS name, COUNT(rc.routeId) AS routes FROM collections c
           LEFT JOIN route_collections rc ON rc.collectionId = c.id
           GROUP BY c.id ORDER BY c.name COLLATE NOCASE""",
    )
    abstract fun observeCounts(): Flow<List<CollectionCount>>

    @Query("SELECT * FROM route_collections")
    abstract fun observeMemberships(): Flow<List<RouteCollectionEntity>>

    @Query(
        """SELECT c.* FROM collections c JOIN route_collections rc ON rc.collectionId = c.id
           WHERE rc.routeId = :routeId ORDER BY c.name COLLATE NOCASE""",
    )
    abstract fun observeForRoute(routeId: String): Flow<List<CollectionEntity>>

    @Query("SELECT * FROM collections ORDER BY name COLLATE NOCASE")
    abstract suspend fun all(): List<CollectionEntity>

    @Query("SELECT * FROM route_collections")
    abstract suspend fun memberships(): List<RouteCollectionEntity>

    /** The column is NOCASE, so this ignores case. */
    @Query("SELECT * FROM collections WHERE name = :name")
    abstract suspend fun byName(name: String): CollectionEntity?

    @Insert
    abstract suspend fun insert(collection: CollectionEntity)

    @Query("UPDATE collections SET name = :name WHERE id = :id")
    abstract suspend fun rename(id: String, name: String)

    @Query("DELETE FROM collections WHERE id = :id")
    abstract suspend fun delete(id: String)

    @Insert(onConflict = OnConflictStrategy.IGNORE)
    abstract suspend fun addMembers(rows: List<RouteCollectionEntity>)

    @Query("DELETE FROM route_collections WHERE collectionId = :collectionId AND routeId IN (:routeIds)")
    abstract suspend fun removeMembers(collectionId: String, routeIds: List<String>)

    /** Puts the route in exactly [collectionIds]; memberships it keeps keep their date. */
    @Transaction
    open suspend fun setForRoute(routeId: String, collectionIds: List<String>, now: Long) {
        removeOthers(routeId, collectionIds)
        addMembers(collectionIds.map { RouteCollectionEntity(routeId, it, now) })
    }

    @Query("DELETE FROM route_collections WHERE routeId = :routeId AND collectionId NOT IN (:keep)")
    protected abstract suspend fun removeOthers(routeId: String, keep: List<String>)
}
```

package io.github.lrosa2.singletrail.data.collections

/** Collection names (spec §8.1, §8.4 step 7, D48). */
object CollectionNames {
    const val MAX_LENGTH = 80
    private val spaces = Regex("""\s+""")
    private val zipSuffix = Regex("""\.zip$""", RegexOption.IGNORE_CASE)

    /** [raw] trimmed, inner whitespace collapsed and cut to [MAX_LENGTH]; null when nothing is left. */
    fun clean(raw: String?): String? = raw?.replace(spaces, " ")?.trim()?.take(MAX_LENGTH)?.trim()?.ifEmpty { null }

    /** The collection a zip called [fileName] fills: its name without ".zip". */
    fun fromZip(fileName: String): String? = clean(fileName.substringAfterLast('/').replace(zipSuffix, ""))
}
```

    fun observeCounts(): Flow<List<CollectionCount>> = dao.observeCounts()

    /** Route ids per collection id; collections without routes are absent. */
    fun observeMembers(): Flow<Map<String, Set<String>>> = dao.observeMemberships().map { rows ->
        rows.groupBy({ it.collectionId }, { it.routeId }).mapValues { it.value.toSet() }
    }

    fun observeForRoute(routeId: String): Flow<List<CollectionEntity>> = dao.observeForRoute(routeId)

    suspend fun all(): List<CollectionEntity> = dao.all()

    /** The names of each route's collections, by route id (for full backups). */
    suspend fun namesByRoute(): Map<String, List<String>> {
        val names = dao.all().associate { it.id to it.name }
        return dao.memberships().groupBy({ it.routeId }, { names.getValue(it.collectionId) })
    }

    /** The collection called [name] (ignoring case and extra spaces), created when there is none; null for a blank name. */
    suspend fun named(name: String): CollectionEntity? {
        val clean = CollectionNames.clean(name) ?: return null
        dao.byName(clean)?.let { return it }
        val created = CollectionEntity(UUID.randomUUID().toString(), clean, clock())
        return try {
            dao.insert(created)
            created
        } catch (_: SQLiteConstraintException) {
            dao.byName(clean) // Made at the same moment elsewhere.
        }
    }

    /** False when [name] is blank or another collection already has it. */
    suspend fun rename(id: String, name: String): Boolean {
        val clean = CollectionNames.clean(name) ?: return false
        val other = dao.byName(clean)
        if (other != null && other.id != id) return false
        dao.rename(id, clean)
        return true

    suspend fun delete(id: String) = dao.delete(id)

/** Length bands of the Filters sheet (spec §8.1, D49). */
enum class LengthBand {
    UP_TO_20_KM, KM_20_TO_40, OVER_40_KM;

    fun contains(meters: Double): Boolean = when (this) {
        UP_TO_20_KM -> meters <= 20_000.0
        KM_20_TO_40 -> meters > 20_000.0 && meters <= 40_000.0
        OVER_40_KM -> meters > 40_000.0
    }
}

/** Climb bands of the Filters sheet (spec §8.1, D49). */
enum class ClimbBand {
    UP_TO_500_M, M_500_TO_1000, OVER_1000_M;

    fun contains(meters: Double): Boolean = when (this) {
        UP_TO_500_M -> meters <= 500.0
        M_500_TO_1000 -> meters > 500.0 && meters <= 1000.0
        OVER_1000_M -> meters > 1000.0
    }
}

/** The Filters sheet (spec §8.1, D49); every filter that is set must match. */
data class LibraryFilters(
    val minStars: Int? = null,
    val length: LengthBand? = null,
    val climb: ClimbBand? = null,
    val notRidden: Boolean = false,
    val loopsOnly: Boolean = false,
) {
    /** How many filters are on, for "Filters (2)". */
    val count: Int get() = listOf(minStars != null, length != null, climb != null, notRidden, loopsOnly).count { it }

    fun matches(route: RouteEntity): Boolean =
        (minStars == null || (route.rating ?: 0) >= minStars) &&
            (length == null || length.contains(route.distanceM)) &&
            // A route without elevation has no known climb, so a climb filter leaves it out.
            (climb == null || route.ascentM?.let(climb::contains) == true) &&
            (!notRidden || route.lastRiddenAt == null) &&
            (!loopsOnly || route.isLoop)
}

/** What the Collection chip shows (spec §8.1, D48). */
sealed interface CollectionChoice {
    data object All : CollectionChoice

    /** Routes that are in no collection. */
    data object NotInAny : CollectionChoice

    data class One(val id: String) : CollectionChoice
}

/** The route ids this choice lets through, from route ids per collection id; null lets everything through. */
fun CollectionChoice.allowed(members: Map<String, Set<String>>, routeIds: Collection<String>): Set<String>? = when (this) {
    CollectionChoice.All -> null
    CollectionChoice.NotInAny -> {
        val grouped = members.values.flatten().toSet()
        routeIds.filterNot { it in grouped }.toSet()
    }
    is CollectionChoice.One -> members[id].orEmpty()
}

/** This choice, given the collection ids that exist: a deleted collection falls back to All (spec §8.1). */
fun CollectionChoice.resolve(existing: Set<String>): CollectionChoice =
    if (this is CollectionChoice.One && id !in existing) CollectionChoice.All else this

/**
 * The routes to show: those [allowed] by the chosen collection (null: all), matching [filters] and every
 * word of [query] in their name or description, in [sort] order, ties by name. "Near me" needs [here];
 * without it the routes stay in name order.
 */
fun arrange(
    routes: List<RouteEntity>,
    sort: LibrarySort,
    filters: LibraryFilters = LibraryFilters(),
    here: Here? = null,
    query: String = "",
    allowed: Set<String>? = null,
): List<RouteEntity> {
    val words = query.split(' ').map(::searchKey).filter { it.isNotBlank() }
    val visible = routes.filter { route ->
        (allowed == null || route.id in allowed) &&
            filters.matches(route) &&
            (words.isEmpty() || searchKey(route.name + " " + route.description.orEmpty()).let { text -> words.all { it in text } })
    }
    val order = when (sort) {
        LibrarySort.NEAR_ME -> if (here == null) {
            byName
        } else {
            // Measured once per route: a comparator would measure each route many times.
            val away = visible.associate { it.id to distanceTo(it, here) }
            compareBy<RouteEntity> { away.getValue(it.id) }.then(byName)
        }
        LibrarySort.NAME -> byName
        LibrarySort.STARS -> compareByDescending<RouteEntity> { it.rating ?: 0 }.then(byName)
        LibrarySort.LENGTH -> compareBy<RouteEntity> { it.distanceM }.then(byName)
        LibrarySort.LAST_RIDDEN -> compareByDescending<RouteEntity> { it.lastRiddenAt ?: Long.MIN_VALUE }.then(byName)
    }
    return visible.sortedWith(order)
}

    /** Routes in no collection, for "Not in a collection (n)". */
    val notInAny: Int = 0,
    /** Words to find in names and descriptions; not remembered across restarts. */
    val query: String = "",
    /** Routes in the library before filtering. */
    val total: Int = 0,
    val loaded: Boolean = false,
    /** Routes picked for sharing or grouping; selection mode while not empty. */
    val selected: Set<String> = emptySet(),
    /** Where the rider is, once "near me" has found out. */
    val here: Here? = null,
    val location: LocationLookup = LocationLookup.IDLE,
    val backupDue: BackupDue? = null,
) {
    /** The chosen collection's name; null for All and Not in a collection. */
    val collectionName: String?
        get() = (collection as? CollectionChoice.One)?.let { chosen -> collections.firstOrNull { it.id == chosen.id }?.name }
}

enum class LocationLookup { IDLE, LOCATING, FAILED }

private data class View(
    val sort: LibrarySort = LibrarySort.NAME,
    val filters: LibraryFilters = LibraryFilters(),
    val collection: CollectionChoice = CollectionChoice.All,
    val here: Here? = null,
    val selected: Set<String> = emptySet(),
    val location: LocationLookup = LocationLookup.IDLE,
    val query: String = "",
)

private data class Groups(val counts: List<CollectionCount>, val members: Map<String, Set<String>>)

class LibraryViewModel(
    private val repository: RouteRepository,
    rides: RideRepository,
    private val collections: CollectionRepository,
    private val settings: SettingsStore,
    private val appVersion: String,
    private val clock: () -> Long = System::currentTimeMillis,
) : ViewModel() {
    private val view = MutableStateFlow(View())

    init {
        // Sort, filters and collection are remembered across restarts (spec §8.1).
        viewModelScope.launch {
            val saved = settings.libraryView()
            val sort = LibrarySort.entries.firstOrNull { it.name == saved.sort } ?: LibrarySort.NAME
            view.update {
                it.copy(
                    // "Near me" needs a fresh location, so it doesn't survive a restart.
                    sort = if (sort == LibrarySort.NEAR_ME) LibrarySort.NAME else sort,
                    filters = LibraryViewCodec.filters(saved),
                    collection = LibraryViewCodec.collection(saved.collection),
                )
            }
        }
    }

    private val groups = combine(collections.observeCounts(), collections.observeMembers(), ::Groups)

    val state: StateFlow<LibraryState> =
        combine(repository.observeRoutes(), rides.observeRides(), settings.lastBackupAt, view, groups) { routes, rideList, lastBackup, v, g ->
            val ids = routes.map { it.id }
            val choice = v.collection.resolve(g.counts.map { it.id }.toSet())
            LibraryState(
                routes = arrange(routes, v.sort, v.filters, v.here, v.query, choice.allowed(g.members, ids)),
                sort = v.sort,
                filters = v.filters,
                collection = choice,
                collections = g.counts,
                notInAny = CollectionChoice.NotInAny.allowed(g.members, ids)?.size ?: 0,
                query = v.query,
                total = routes.size,
                loaded = true,
                selected = v.selected.intersect(ids.toSet()),
                here = v.here,
                location = v.location,
                backupDue = BackupReminder.due(lastBackup, clock(), routes.size, rideList.size),
            )
        }
            .flowOn(Dispatchers.Default) // near me measures every route's outline: not on the main thread
            .stateIn(viewModelScope, SharingStarted.WhileSubscribed(5_000), LibraryState())

    fun setSort(value: LibrarySort) {
        view.update { it.copy(sort = value) }
        save()
    }

    fun setFilters(value: LibraryFilters) {
        view.update { it.copy(filters = value) }
        save()
    }

    fun setCollection(value: CollectionChoice) {
        view.update { it.copy(collection = value) }
        save()
    }

    fun setQuery(value: String) {
        view.update { it.copy(query = value) }
    }

    /** "Show all routes": every collection, no filters, no search. */
    fun showAll() {
        view.update { it.copy(collection = CollectionChoice.All, filters = LibraryFilters(), query = "") }
        save()
    }

    fun locating() {
        view.update { it.copy(location = LocationLookup.LOCATING) }
    }

    /** The answer to a "near me" lookup; null when no position could be found. */
    fun located(here: Here?) {
        view.update {
            if (here == null) it.copy(location = LocationLookup.FAILED) else it.copy(here = here, location = LocationLookup.IDLE)
        }
    }

    fun toggleSelected(id: String) {
        view.update { it.copy(selected = if (id in it.selected) it.selected - id else it.selected + id) }
    }

    fun clearSelection() {
        view.update { it.copy(selected = emptySet()) }
    }

    /** Files for the selected routes, written into [dir]. */
    suspend fun shareSelected(dir: File): RouteSharing.Prepared? {
        val selected = state.value.routes.filter { it.id in state.value.selected }
        if (selected.isEmpty()) return null
        return RouteSharing.prepare(selected, repository, dir, appVersion, clock())
    }

    private fun save() {
        val v = view.value
        viewModelScope.launch { settings.saveLibraryView(LibraryViewCodec.settings(v.sort, v.filters, v.collection)) }
    }
}

/** Manage collections (spec §8.1): counts; new, rename, delete (the routes stay). */
@OptIn(ExperimentalMaterial3Api::class)
@Composable
fun ManageCollectionsScreen(collections: CollectionRepository, onBack: () -> Unit) {
    val list by collections.observeCounts().collectAsState(initial = null)
    val scope = rememberCoroutineScope()
    var creating by remember { mutableStateOf(false) }
    var renaming by remember { mutableStateOf<CollectionCount?>(null) }
    var renameError by remember { mutableStateOf(false) }
    var deleting by remember { mutableStateOf<CollectionCount?>(null) }

    Scaffold(
        topBar = {
            TopAppBar(
                title = { Text(stringResource(R.string.collections_title)) },
                navigationIcon = {
                    IconButton(onClick = onBack) {
                        Icon(Icons.AutoMirrored.Filled.ArrowBack, contentDescription = stringResource(R.string.action_back))
                    }
                },
            )
        },
        floatingActionButton = {
            ExtendedFloatingActionButton(
                onClick = { creating = true },
                icon = { Icon(Icons.Filled.Add, contentDescription = null) },
                text = { Text(stringResource(R.string.collection_new)) },
            )
        },
    ) { padding ->
        val current = list ?: return@Scaffold
        if (current.isEmpty()) {
            Text(
                stringResource(R.string.collections_empty),
                Modifier.padding(padding).padding(24.dp),
                style = MaterialTheme.typography.bodyLarge,
            )
        } else {
            LazyColumn(
                Modifier.padding(padding).fillMaxSize(),
                contentPadding = PaddingValues(start = 16.dp, end = 16.dp, top = 8.dp, bottom = 96.dp),
                verticalArrangement = Arrangement.spacedBy(8.dp),
            ) {
                items(current, key = { it.id }) { c ->
                    CollectionRow(c, onRename = { renameError = false; renaming = c }, onDelete = { deleting = c })
                }
            }
        }
    }

    if (creating) {
        CollectionNameDialog(
            title = stringResource(R.string.collection_new),
            initial = "",
            error = null,
            onSave = { name ->
                creating = false
                scope.launch { collections.named(name) }
            },
            onDismiss = { creating = false },
        )
    }
    renaming?.let { c ->
        CollectionNameDialog(
            title = stringResource(R.string.collection_rename_title),
            initial = c.name,
            error = if (renameError) stringResource(R.string.collection_name_taken) else null,
            onSave = { name ->
                scope.launch {
                    if (collections.rename(c.id, name)) renaming = null else renameError = true
                }
            },
            onDismiss = { renaming = null },
        )
    }
    deleting?.let { c ->
        AlertDialog(
            onDismissRequest = { deleting = null },
            title = { Text(stringResource(R.string.collection_delete_title)) },
            text = { Text(pluralStringResource(R.plurals.collection_delete_body, c.routes, c.name, c.routes)) },
            confirmButton = {
                TextButton(onClick = {
                    deleting = null
                    scope.launch { collections.delete(c.id) }
                }) { Text(stringResource(R.string.action_delete)) }
            },
            dismissButton = { TextButton(onClick = { deleting = null }) { Text(stringResource(R.string.action_cancel)) } },
        )
    }
}

        if (ids.size < 2) return
